# 二维线性变换 · 交互演示

线性代数「二维线性变换」的网页演示，课堂展示用。打开就能用，无需安装任何软件。

## 打开方式

**有网（推荐）** —— 浏览器直接打开：

https://unlawrence.github.io/linear-transform-web/

手机、平板、Windows / Mac 电脑的浏览器都支持。

**离线 / 本地**：

- Mac：双击 `start.command`
- Windows：双击 `start.bat`（需要电脑已安装 Python）

启动后浏览器会自动打开本地页面。

## 界面说明

- 画面中央的灰色虚线是「原图」（房子），橙色是它被矩阵变换后的结果。
- 蓝色、红色箭头是基向量 e₁、e₂ 和变换后的 Ae₁、Ae₂。
- 底部「A」的四个格子是 2×2 矩阵，直接改数字，图形实时变化。
- 底部滑块：旋转角度。

## 菜单

「变换」：单位矩阵 / 伸缩 / 旋转 / 剪切 / 反射 / 投影，一键切换演示。

「显示」：切换原图（房子 / 80 周年图片）、显示网格、显示教学信息。

「教学信息」：展示行列式 det、秩 rank、面积缩放倍数，以及方向是否翻转。
